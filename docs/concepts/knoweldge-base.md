# Knowledge Base

A knowledge base is a collection of knowledge sources. This NOT is a physical database, but a logical organization of similar knowledge sources.

## Example
- Knowledge Sources
  - S3
  - Cloud Storage
  - Local File System
  - PostgreSQL
  - YouTube
  - GitHub

- Knowledge Base
  - Finances
    - Local File System (financial statements)
    - PostgreSQL (finance database)
  - Marketing
    - S3 (marketing assets)
    - PostgreSQL (marketing database)
    - YouTube (marketing videos)
