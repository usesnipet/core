# Api key

An API key is a credential that allows you to access the API. It is a string of characters that is used to authenticate requests to the API.
Initially, the API key can access all the API endpoints.

The API key can be associated with a project. If the API key is associated with a project, it will only be able to access the API endpoints that are associated with the project. If the API key is not associated with a project, it will be able to access all the API endpoints.
