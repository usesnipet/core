# Source Module

## Controller
- Name: SourceController
- Description: Controller for managing sources
- Dependencies:
  - SourceService

### Methods
- find
  - Description: Find a source by id
  - Authentication
    - ApiKeyGuard: Check if the API key is associated to the project, otherwise it will return an error.
  - Params:
    - projectId: string
    - id: string
  - Logic:
    - Call the `SourceService.find` method with the projectId, id and includeEncryptedFields is false (only return the non-encrypted fields)
  - Returns:
    - 200: SourceEntity
    - 400: BadRequestException
    - 401: UnauthorizedException
    - 403: ForbiddenException
    - 404: NotFoundException
    - 500: InternalServerErrorException
- findMany
  - Description: Find many sources
  - Authentication
    - ApiKeyGuard: Check if the API key is associated to the project, otherwise it will return an error.
  - Params:
    - projectId: string
  - Query:
    - filterOptions: FilterOptions<SourceEntity>
  - Returns:
    - 200: SourceEntity[]
    - 401: UnauthorizedException
    - 403: ForbiddenException
    - 500: InternalServerErrorException
- create
  - Description: Create a new source
  - Authentication
    - ApiKeyGuard: Check if the API key is associated to the project, otherwise it will return an error.
  - Body: CreateSourceDto
  - Returns:
    - 201: SourceEntity
    - 400: BadRequestException
    - 401: UnauthorizedException
    - 403: ForbiddenException (if the API key is associated to a project)
    - 500: InternalServerErrorException
- update
  - Description: Update a source
  - Authentication
    - ApiKeyGuard: Check if the API key is associated to the project, otherwise it will return an error.
  - Params:
    - projectId: string
    - id: string
  - Body: UpdateSourceDto
  - Returns:
    - 200: SourceEntity
    - 400: BadRequestException
    - 401: UnauthorizedException
    - 403: ForbiddenException (if the API key is associated to other project)
    - 500: InternalServerErrorException
- delete
  - Description: Delete a source
  - Authentication
    - ApiKeyGuard: Check if the API key is associated to the project, otherwise it will return an error.
  - Params:
    - projectId: string
    - id: string
  - Query:
    - force?: boolean
  - Returns:
    - 200: void
    - 400: BadRequestException
    - 401: UnauthorizedException
    - 403: ForbiddenException (if the API key is associated to other project)
    - 500: InternalServerErrorException

## Service

- Name: SourceService
- Description: Service for managing sources

### Dependencies

- AJVService
- DatabaseService
- Logger

### Methods

- find
  - Description: Find a source by id (return the source)
  - Logic:
    - Find the source by id and projectId in the database
    - Decrypt the config (encrypted fields) if includeEncryptedFields is true
    - Mask the config (encrypted fields) if includeEncryptedFields is false (only return the non-encrypted fields)
  - Parameters:
    - projectId: string
    - id: string
    - includeEncryptedFields: boolean - if true, the source will be returned with the encrypted fields, otherwise it will be returned with config that are not encrypted
  - Returns: Promise<Result<SourceEntity, DBError>>
- findMany
  - Description: Find many sources (return the sources)
  - Logic:
    - Find the sources in the database
    - Decrypt the config (encrypted fields) if includeEncryptedFields is true
    - Mask the config (encrypted fields) if includeEncryptedFields is false (only return the non-encrypted fields)
  - Parameters:
    - projectId: string
    - filterOptions: FilterOptions<SourceEntity>
    - includeEncryptedFields: boolean - if true, the source will be returned with the encrypted fields, otherwise it will be returned with config that are not encrypted
  - Returns: Promise<Result<SourceEntity[], DBError>>
- create
  - Description: Create a new source (returns the created project)
  - Logic:
    - Validate the input (config fields) using AJV
    - Encrypt the config (encrypted fields) using `AJVService.encrypt`
    - Create a new source in the database
  - Parameters:
    - projectId: string
    - input: CreateSourceDto
    - includeEncryptedFields: boolean - if true, the source will be returned with the encrypted fields, otherwise it will be returned with config that are not encrypted
  - Returns: Promise<Result<SourceEntity, DBError>>
- update
  - Description: Update a source (returns the updated source)
  - Logic:
    - Validate the input (config fields) using AJV
    - Encrypt the config (encrypted fields) using `AJVService.encrypt`
    - Update the source in the database
  - Parameters:
    - projectId: string
    - id: string
    - input: UpdateSourceDto
    - includeEncryptedFields: boolean - if true, the source will be returned with the encrypted fields, otherwise it will be returned with config that are not encrypted
  - Returns: Promise<Result<SourceEntity, DBError>>
- delete
  - Description: Delete a source (returns void)
  - Logic:
    - Delete the source from the database
  - Parameters:
    - projectId: string
    - id: string
  - Returns: Promise<Result<void, DBError>>
